痛点

你是不是每次都在重复同样的话？

每次让 AI 帮你做事，你得重新解释一遍：
你是谁、你的产品是什么、你的风格偏好、上次踩过的坑、不要用哪些词……

说一次还行。说十次就累了。说一百次 —

我到底是在用工具，还是在训练工具？

🔁

Skill 解决这个问题

  • 你的身份和偏好 → 不用每次自我介绍
  • 你踩过的坑 → 不用每次重新提醒
  • 你验证过的工作流 → 不用每次从零描述

Skill = 把你说过一百遍的话，变成只说一次

案例

Demo Generator — 从一句吐槽到一个 Skill

我的痛点 — 做 Demo

  • 我在做外场 AI付，拓展商户
  • 需要把 AI付链路放到不同场景展示给商户
  • 给 A 商户要 Demo，给 B 商户要 Demo…
  • 一个 Demo 最快半天
  • 找设计排期？下周吧。用 relay？还要截图标注半天
我要做一个 skill，这是一个工具，把产品想法直接变成可演示的 HTML，双击就能开。

第一版：能用但粗糙

最初就是一个简单的 prompt —— 告诉它做一个交互原型 HTML。能出活，但问题很多：

❌ 文案 AI 味很重
「智能赋能」「极致丝滑」随处可见
❌ 暴露内部算法
把内部算法细节暴露给外部受众
❌ 视觉风格飘
每次生成风格都不一样

💡 关键发现：能用 ≠ 好用，要通过反复反馈把经验沉淀成规则

反馈 → 规则

找个案例做一遍，反馈踩坑经验

我现在要做一个海尔冰箱 AI付的 demo，包含：补货下单、语音下单、支付全链路。AI付新户需要开通，老户直接支付，使用声纹核验。

输入信息有限，展示内容文案不对 → 把每一次反馈都沉淀成规则

你不要用签约这么正式的语言，内部的规则不要对外暴露，我的每一笔都需要京东AI付的品牌心智，但是场景方的颜色你需要自己去搜集材料……后续所有的反馈你都要沉淀成 skill 里的通用规则

每次反馈都沉淀成规则

写进 config/domain-rules.json：

⚠️ 支付场景禁用「签约」，使用「开通/绑定」
用户认为「签约」太正式
⚠️ 三力决策模型不在 Demo 中展示
内部算法不暴露给外部受众
⚠️ 开通流程必须是跳转页面
真实产品逻辑是跳转到绑定页完成
⚠️ AI-slop 文案一律删
「智能赋能」「一站式」「无缝衔接」出现即失败
⚠️ 不编造看起来真实的数据
所有数据由我提供

💡 这些规则就是 Anthropic 说的 Gotchas —— 模型不知道的隐性知识

站在巨人肩膀上

单个 Skill 搞不定所有事

我发现 skill 可以实现诉求，但它不懂产品、不懂设计、容易陷入伪需求。我去 GitHub 上找好用的 Skill：

Skill类型核心价值

Frontend Slides演示文稿HTML 幻灯片 + PPT

如果我的需求没有说清楚你用 grill-me 追问我，你用 prd-critic 方案评估，输出按 frontend-design 和 frontend-slides 规范来

7 个 Skill 各司其职

demo-generator ← 主控 ├── frontend-design ← 视觉规范 ├── frontend-slides ← 幻灯片 ├── grill-me ← 拷打需求 ├── problem-clarity ← 评判引擎 └── prd-critic ← 方案评估

完善后的工作流六阶段

Phase 1 拷打式需求挖掘 — 逐个追问
Phase 2 锁定视觉方向 — 选定锚点不漂移
Phase 3 生成 Demo — HTML/PPT/视频
Phase 4 自检迭代 — 核心/逻辑/文案
Phase 5 反向拷打 — 模拟尖锐质疑
Phase 6 一源多版 — 客户版+决策者版+传播版

爱马仕

Hermes Agent 怎么工作？

传统：你踩坑 → 你总结 → 你写 SKILL.md。人是瓶颈。

传统 SkillHermes 蒸馏
谁提取你自己AI 自动
什么时候事后总结任务后自动触发
怎么进化你手动更新使用中自改进
记忆每次从零跨会话持久

安装

# macOS / Linux curl -fsSL https://hermes-agent.nousresearch.com/install.sh | bash # 一键配置 hermes setup --portal # 查看自动提取的技能 /skills

实操体验

第一次 你告诉它怎么做（从零开始）

第二次 它记住了，主动复用

第三次 它已经沉淀成了 Skill

✅ 你不需要跟它说「帮我写个 Skill」

你只需要正常工作。比如连续做了 3 个支付 Demo，它自己把「做支付 Demo」沉淀成了一个 Skill。

💡 建议：两者结合

  • 核心高频任务 → 手写 Skill（精确）
  • 长尾低频任务 → 爱马仕自动蒸馏
LEVEL 3

四、思维蒸馏 — 女娲 Skill

不是复制一个人说过什么，而是提取他怎么想

维度提取什么为什么重要
🧠 心智模型用什么镜片看世界决定看到/忽略什么
⚡ 决策启发式「如果X则Y」规则快速判断的核心
🗣️ 表达 DNA怎么说话、什么节奏让 Skill 像那个人
🚫 反模式绝对不会做什么边界比能力更重要
🎯 诚实边界做不到什么防止过度信任

💡 最实用场景 — 蒸馏你自己

和 Claude 说：「蒸馏我自己，我手上有这些素材：我的文章 / 决策备忘录 / 会议录音 / 聊天记录」

女娲执行流程

Phase 0 入口分流 ├ 明确人名 → 直接蒸馏 └ 模糊需求 → 诊断推荐 → 再蒸馏 Phase 0.5 深度调研（6 Agent 并行） → 著作与系统思考 → 长对话与即兴思考 → 碎片表达与风格 DNA → 他者视角与批评 → 决策记录与行动 → 人物时间线 Phase 1 提炼思维框架 Phase 2 生成可运行 Skill

实际产出示例

  • 5 个心智模型
  • 7 条决策启发式
  • 表达 DNA：简短、直觉驱动、感受先行
  • 反模式：不评判高低、不回应恶意攻击
