1. 痛点

你是不是每次都在重复同样的话？

每次让 AI 帮你做事，你得重新解释一遍：
你是谁、你的产品是什么、你的风格偏好、上次踩过的坑、不要用哪些词……

说一次还行。说十次就累了。说一百次 —

我到底是在用工具，还是在训练工具？

🔁

Skill 解决这个问题

  • 你的身份和偏好 → 不用每次自我介绍
  • 你踩过的坑 → 不用每次重新提醒
  • 验证过的工作流 → 不用每次从零描述

Skill = 把重复的话固化成文件，AI 自动加载

2. 基本结构

Skill 长什么样？

--- name: my-skill-name description: "用户说「XXX」时加载" --- # Skill 名称 一句话定位。 ## Gotchas 1. [你踩过的坑] 2. [模型容易犯的错] ## 工作流 Phase 1 → Phase 2 → Phase 3 ## Phase 1: [阶段名] 目标、输入输出、停止条件

要素作用

3. 案例

Demo Generator 的诞生

我的痛点 — 做 Demo

  • 给 A 商户演示要 Demo
  • 给 B 商户演示要 Demo
  • 一个 Demo 最快半天
  • 找设计排期？下周吧
我跟 Claude 说：「我需要一个工具，把产品想法直接变成可演示的 HTML，双击就能开。」

第一版能用但粗糙 — 文案 AI 味重、风格飘、暴露内部细节

关键动作：每次反馈沉淀成规则

⚠️ 支付场景禁用「签约」，使用「开通/绑定」
原因：用户认为「签约」太正式
⚠️ 三力决策模型不在 Demo 中展示
原因：内部算法不暴露给外部受众
⚠️ 开通流程必须是跳转页面
原因：真实产品逻辑是跳转到绑定页
⚠️ AI-slop 文案一律删
「智能赋能」「一站式」「无缝衔接」出现即失败
⚠️ 不编造看起来真实的数据
所有数据由我提供

6. 爱马仕

Hermes Agent 怎么工作？

传统 SkillHermes 蒸馏
谁提取你自己AI 自动
什么时候事后总结任务后自动触发
怎么进化你手动更新使用中自改进
记忆每次从零跨会话持久

安装

# macOS / Linux curl -fsSL https://hermes-agent.nousresearch.com/install.sh | bash # 配置 hermes setup --portal # 查看自动提取的技能 /skills

实操体验

第一次 你告诉它怎么做（从零开始）

第二次 它记住了，主动复用

第三次 它已经沉淀成了 Skill

✅ 你不需要跟它说「帮我写个 Skill」

你只需要正常工作。比如连续做了 3 个支付 Demo，它自己把「做支付 Demo」沉淀成了一个 Skill。

💡 建议：两者结合

  • 核心高频任务 → 手写 Skill（精确）
  • 长尾低频任务 → 爱马仕自动蒸馏
LEVEL 3

思维蒸馏 — 女娲 Skill

不是复制一个人说过什么，而是提取他怎么想

维度提取什么
🧠 心智模型他用什么镜片看世界
⚡ 决策启发式「如果 X，则 Y」的直觉规则
🗣️ 表达 DNA怎么说话、什么节奏
🚫 反模式绝对不会做什么
🎯 诚实边界这个 Skill 做不到什么

执行流程

Phase 0 入口分流 ├ 明确人名 → 直接蒸馏 └ 模糊需求 → 诊断推荐 → 再蒸馏 Phase 0.5 深度调研（6 Agent 并行） → 著作与系统思考 → 长对话与即兴思考 → 碎片表达与风格 DNA → 他者视角与批评 → 决策记录与行动 → 人物时间线 Phase 1 提炼思维框架 Phase 2 生成可运行 Skill

💡 最实用场景 — 蒸馏你自己

和 Claude 说：「蒸馏我自己，我手上有这些素材：我的文章 / 决策备忘录 / 会议录音 / 聊天记录」
